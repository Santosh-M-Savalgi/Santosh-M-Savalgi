## 🚀 Featured Projects

### 🎓 [AAA: Autonomous Academic Agent](https://github.com/Santosh-M-Savalgi/AutonomusAcademicAssistantAgents)
Multi-agent adaptive tutoring system grounded in Bloom's *2 Sigma Problem* (SDG 4 & 10).
- **6-node LangGraph `StateGraph`**: parse → retrieve → web-retrieve → tutor → quiz → evaluate
- **58 REST endpoints** across 11 routers, **671 pytest tests** across 32 files
- PostgreSQL (asyncpg) + Redis checkpointing, ChromaDB, Tavily web search, MinIO/S3, Alembic, JWT auth, Prometheus + OpenTelemetry
- Pluggable LLM providers (DeepSeek primary, Gemini fallback)

`Python` `FastAPI` `LangGraph` `PostgreSQL` `Redis` `ChromaDB` `Docker`

### 🛍️ [Product Intelligence System](https://github.com/Santosh-M-Savalgi/onespace-product-intelligence)
Visual product intelligence using **CLIP embeddings + FAISS** vector search.
- Smart recommendations, catalog deduplication, reverse image search
- Deduplicated **3,999 → 3,872** unique products at a 0.975 similarity threshold with **88.9% intra-cluster purity**

`Python` `CLIP` `FAISS` `React` `Vite` `Framer Motion`

### 📩 [SMS Spam Detector with Fraud URL Detection](https://github.com/Santosh-M-Savalgi/sms-spam-detector-with-fraud-url-detection)
Spam message classifier with an added fraud URL detection layer to flag malicious links.

`Python` `scikit-learn` `NLP` `TF-IDF`
